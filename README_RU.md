# NEXORA

Android-приложение с интерфейсом ИИ-чата на Kotlin и Jetpack Compose.

## Сборка APK
Открой вкладку **Actions** в GitHub, выбери **Build NEXORA APK** и нажми **Run workflow**. После успешной сборки скачай артефакт **NEXORA-debug-apk**.

## Подключение ИИ
В приложении открой «Настройки» и укажи URL backend-сервера. Приложение отправляет POST-запрос на `/chat` с JSON `{"message":"..."}` и ожидает JSON-ответ `{"reply":"..."}`.

Не помещай API-ключи в APK или публичный репозиторий. Нужен отдельный backend, который хранит секретный ключ на сервере.
